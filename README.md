# OLX 巴西分类广告数据集样本

<h2>包含 1,000 条记录的数据集样本</h2>

<a href="https://www.bright.cn/">
    <img src="https://github.com/bright-cn/OLX-Brazil-marketplace-dataset-samples/blob/main/datasets-image.png" alt="Bright Data 数据集" />

此 **OLX 巴西市场广告数据集样本**包含 **1,000 条记录**，通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `body` | 广告的主要内容或描述。 |
| `subject` | 广告的标题。 |
| `Currency` | 标价所使用的货币，通常为 BRL（巴西雷亚尔）。 |
| `priceValue` | 广告商品的金额或价格。 |
| `ProfessionalAnnouncement` | 表示广告是否由专业卖家发布（true/false）。 |
| `category` | 表示广告具体类别的数字 ID。 |
| `parentCategoryName` | 广告所属的父类别，例如“Autos e peças”。 |
| `categoryName` | 广告的具体类别名称，例如“Carros, vans e utilitários”。 |
| `PublicationDate` | 广告发布的日期和时间。 |
| `adReply` | 广告收到的回复或响应数量。 |
| `friendlyUrl` | 用于在线查看广告的 URL 链接。 |
| `Sellername` | 发布广告的卖家或实体名称。 |
| `Destaques` | 广告的亮点或主要特点。 |
| `phone` | 卖家提供的联系电话。 |
| `images` | 与广告相关的图片 URL 或链接。 |
| `NumberOfImages` | 广告中包含的图片数量。 |
| `neighbourhood` | 商品可用或发布地点所在的街区。 |
| `municipality` | 广告发布地所在的市镇或城市。 |
| `zipcode` | 与广告发布地点相关的邮政编码。 |
| `zone` | 市镇内的区域或片区分类。 |
| `region` | 广告发布地所属的更大区域或州。 |
| `vehicleSpecificData` | 与车辆相关的其他规格（如适用）。 |
| `pubSpecificData` | 与广告相关的特定发布数据或元数据。 |
| `trackingSpecificData` | 用于跟踪广告表现和互动指标的数据。 |
| `searchboxes` | 有关所应用搜索筛选条件的信息。 |
| `breadcrumbUrls` | 用于在网站内定位广告的面包屑导航 URL。 |
| `tags` | 与广告相关的关键词或标签。 |
| `featured` | 表示广告是否为精选或高亮广告（true/false）。 |
| `vehicleTags` | 车辆广告专用标签。 |
| `description` | 广告附带的详细说明或描述。 |
| `listTime` | 广告首次发布时的时间戳。 |
| `isFeatured` | 表示广告当前是否在平台上被设为精选的布尔值。 |
| `Marca` | 车辆的品牌或制造商（如适用）。 |
| `TipoDeVeiculo` | 所发布车辆的类型或类别。 |
| `Quilometragem` | 车辆的行驶里程或公里数。 |
| `PotenciaDoMotor` | 车辆的发动机功率规格。 |
| `Combustível` | 车辆使用的燃料类型。 |
| `ManufactureYear` | 车辆或商品的生产年份。 |
| `properties` | 与广告相关的其他房产数据。 |
| `locations` | 与广告相关的地理位置数据。 |
| `url` | 用于在线访问广告的直接 URL 链接。 |
| `adId` | 分配给每条广告的唯一标识符。 |
| `listId` | 与广告条目关联的刊登 ID。 |
| `seller_id` | 卖家或广告主的唯一标识符。 |
| `destaque` | 广告的主要亮点或特点。 |
| `tipo_anunciante` | 广告主的类型，例如个人或公司。 |


## 使用场景

### 1. 市场趋势分析
分析广告数据，识别巴西线上市场的新兴趋势，为战略业务决策提供支持。

### 2. 竞争情报
利用数据集监测竞争对手的定价和广告策略，深入了解市场定位。

### 3. 消费者行为洞察
研究消费者互动指标和广告响应，了解消费者偏好并优化营销策略。
